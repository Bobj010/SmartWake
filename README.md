# SmartWake

Android-приложение: умный будильник с мини-играми и проверкой пробуждения (решение математических примеров, сканирование QR-кода/штрихкода, встряхивание).

Готовый установочный файл лежит в корне репозитория: **[SmartWake.apk](SmartWake.apk)**.

## Возможности
- Обычный будильник с выбором времени, дней недели и повторов
- Отключение через мини-игры:
  - Решение математических примеров (настраиваемая сложность)
  - Сканирование заданного QR-кода или штрихкода (через камеру)
  - Встряхивание телефона (акселерометр)
- Постепенное нарастание громкости сигнала
- Работа поверх экрана блокировки

## Стек
- Kotlin, Jetpack Compose
- Room (база данных SQLite)
- CameraX + Google ML Kit Barcode Scanning
- AlarmManager, Foreground Service
