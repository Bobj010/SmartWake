# Продуктовая спецификация SmartWake (PRODUCT_SPEC)

> **Назначение документа**: Описание мобильного приложения простым языком без программного кода и узкоспециализированных технических терминов. Документ служит эталоном пользовательского опыта и сценариев взаимодействия (Single Source of Truth для человека).

---

## 1. Концепция и цель продукта

**SmartWake** — это бескомпромиссный умный будильник для смартфонов на Android.

* **Главная цель**: Гарантировать 100% подъем пользователя с постели и преодоление «утреннего автопилота» (рефлекторного выключения звука в полусне).
* **Ключевой механизм**: Отсутствие простой кнопки «Выключить». Чтобы остановить сигнал, пользователь обязан:
  1. Либо физически встать, дойти до другой комнаты (ванная, кухня) и отсканировать камерой смартфона заранее привязанный QR-код или бытовой штрихкод.
  2. Либо запустить работу когнитивных функций мозга, решив заданное количество математических примеров или логическую мини-игру.

## 2. Границы первой версии (Скоуп MVP)

### Что входит строго в MVP:
1. **Полноценный локальный будильник**:
   - Создание, включение/выключение, удаление и редактирование будильников.
   - Выбор точного времени и дней недели (повторы).
   - Плавное нарастание громкости звонка (от тишины до максимума за 30 секунд), чтобы не вызывать панического шока у сердца.
   - Вибрация с настраиваемым паттерном.
2. **QR / Штрих-код капча (Физический подъем)**:
   - Быстрая привязка любого существующего в доме кода (QR-код на стикере, штрихкод на банке с кофе или тюбике зубной пасты).
   - При звонке: включение камеры прямо поверх экрана блокировки со сканированием и мгновенным выключением звука при совпадении.
   - Кнопка включения фонарика прямо в видоискателе для темной комнаты.
3. **Математическая капча (Когнитивный разгон)**:
   - 3 уровня сложности: Простой (сложение/вычитание), Средний (умножение двузначных чисел), Сложный (комбинированные выражения со скобками).
   - Настройка числа примеров (от 1 до 5).
   - Удобная экранная цифровая панель с крупными кнопками.
4. **Тест памяти (Memory Tiles)**:
   - Сетка $3 \times 3$, где на 3 секунды подсвечиваются ячейки. Пользователь должен повторить их расположение.
5. **Встряхивание (Shake Test)**:
   - Отключение через 30–50 интенсивных встряхиваний телефона с индикатором прогресса.
6. **Надежность и защита**:
   - Гарантированное срабатывание при заблокированном экране и в режиме энергосбережения.
   - Автоматическое восстановление всех будильников при перезагрузке смартфона.
   - Аварийный режим «Safe-Exit» (отключение по аварийному 6-значному PIN-коду или через 5 минут непрерывного звонка на случай утери QR-кода).
7. **Журнал истории**:
   - Просмотр статистики: во сколько звонил будильник, во сколько был отключен и сколько минут занял подъем.

### Что сознательно исключено из MVP (перенесено в Roadmap):
* Облачная синхронизация аккаунтов (все данные хранятся только локально на телефоне).
* Социальные функции («разбуди друга»).
* Распознавание шагомера через фоновый GPS/шагомер.
* Интеграции с умным домом по Wi-Fi (Home Assistant / умные лампочки).

## 3. Пользовательские сценарии (User Scenarios)

### Сценарий 1. Вечерняя настройка первого QR-будильника
1. Пользователь запускает SmartWake. На главном экране видит пустой список и кнопку «+».
2. Нажимает «+». Открывается экран создания будильника.
3. Устанавливает время: `07:00`, дни: `Пн, Вт, Ср, Чт, Пт`.
4. В блоке «Способ отключения» выбирает **«QR / Штрих-код»**.
5. Приложение предлагает: «Отсканируйте код, который будет отключать этот будильник».
6. Пользователь идет в ванную комнату, наводит камеру на штрих-код зубной пасты. Приложение издает приятный виброотклик: «Код успешно привязан: Ванная комната».
7. Пользователь сохраняет будильник. В списке появляется карточка с временем 07:00 и иконкой QR-кода.

### Сценарий 2. Утреннее пробуждение по QR-коду
1. В 07:00 смартфон начинает плавно играть мелодию, постепенно наращивая громкость.
2. Экран автоматически загорается на максимальную яркость, отображая крупные часы `07:00` и надпись: «Пора вставать! Миссия: QR-код».
3. На экране **нет** привычного ползунка или крестика «Выключить».
4. Доступны две кнопки:
   - Большая пульсирующая: **«СКАНИРОВАТЬ QR-КОД»**.
   - Небольшая внизу: **«Отложить на 5 минут»** (счетчик показывает «Осталась 1 попытка»).
5. Пользователь берет телефон, встает с кровати, идет в ванную комнату.
6. Нажимает «Сканировать». Включается камера с зеленой рамкой прицела. При слабом освещении нажимает иконку фонарика.
7. Наводит камеру на штрих-код пасты. Как только код попадает в рамку, раздается короткий победный звуковой сигнал, музыка немедленно умолкает, экран сообщает: «Отличная работа! Время подъема: 07:02».

### Сценарий 3. Пробуждение с математической задачей
1. Будильник звонит в 08:00. Способ отключения — 3 математических примера среднего уровня.
2. Пользователь нажимает «Решить примеры».
3. Появляется экран: `Пример 1 из 3: 47 + 38 = ?`
4. Пользователь вводит на экранной клавиатуре `85`. Ответ мгновенно принимается, появляется следующий пример: `14 * 6 = ?`.
5. После правильного ввода третьего примера будильник выключается. К этому моменту мозг уже полностью перешел из режима полудремы в активное бодрствование.

## 4. Поведение в нештатных и кризисных ситуациях

| Внештатная ситуация | Поведение системы |
| :--- | :--- |
| **Пользователь потерял QR-код** (выбросил тюбик пасты, смыло наклейку) | Внизу экрана сканирования доступна скрытая кнопка «Аварийный ввод PIN-кода». Ввод заранее настроенного 6-значного пина выключает звонок. Если пин-код забыт, через 5 минут непрерывного звонка срабатывает таймаут автоотключения, чтобы не сжечь динамик смартфона. |
| **Смартфон перезагрузился ночью** (обновление системы / разрядка) | Системная служба автозапуска моментально восстанавливает все запланированные сигналы сразу после загрузки Android. Будильник гарантированно прозвонит вовремя. |
| **Отсутствует интернет** | Приложение на 100% автономно. Интернет не требуется ни для сканирования камеры, ни для будильника, ни для хранения настроек. |
| **Пользователь пытается убавить громкость качелькой на корпусе** | Приложение перехватывает системный звуковой поток аларма: при попытке уменьшить звук громкость принудительно возвращается на заданный уровень звонка. |
| **Пользователь смахнул приложение из списка недавних (Task Killer)** | Системный таймер `AlarmManager.setAlarmClock` живет внутри системного ядра Android вне процесса приложения — в назначенную секунду ОС сама разбудит приложение и запустит службу звонка. |

## 5. Дизайн-система и пользовательский интерфейс

* **Эстетика**: High-contrast OLED Dark Theme (глубокий черный фон `#0D0E15` с неоновыми функциональными акцентами).
* **Цветовая палитра**:
  - Основной фон: Deep Slate Black (`#0B0C10`)
  - Карточки и подложки: Slate Surface (`#1F2833`)
  - Акцент активности (кнопки действия, переключатели): Electric Indigo (`#6366F1`) или Cyber Teal (`#14B8A6`)
  - Цвет предупреждения/тревоги: Amber Orange (`#F59E0B`) и Soft Crimson (`#EF4444`)
  - Текст: Ослепительно белый (`#FFFFFF`) для цифр часов и приглушенный серый (`#9CA3AF`) для второстепенных подписей.
* **Эргономика (Thumb Zone)**:
  - Все ключевые интерактивные элементы (кнопка добавления, старт сканирования, клавиатура калькулятора) располагаются в нижней половине экрана под палец одной руки.
  - Минимальный размер сенсорной зоны: $56 \times 56\text{ dp}$ (удобно нажимать даже сонными пальцами).
